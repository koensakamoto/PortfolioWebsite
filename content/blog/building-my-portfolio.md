# Building My Portfolio Website

Every developer needs a portfolio. Here's how I built mine.

## Tech Stack

- **Next.js** - React framework with great DX
- **Tailwind CSS** - Utility-first CSS that actually makes sense
- **TypeScript** - Because I like catching bugs early
- **Vercel** - Deployment that just works

## Design Decisions

I went with a neobrutalist design—bold borders, solid shadows, high contrast. It's trendy right now, but I genuinely like how it looks. The offset shadows give everything a tactile, almost physical feel.

## Features

- Dark/light mode that respects system preferences
- Markdown-based blog (you're reading it!)
- Responsive design
- Contact form
- Project showcase

## Lessons Learned

1. Start simple and iterate
2. Don't over-engineer (I definitely over-engineered some parts)
3. Placeholder content is fine—just ship it
4. You'll never be 100% happy with it, and that's okay
