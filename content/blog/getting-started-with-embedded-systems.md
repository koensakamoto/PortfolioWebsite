# Getting Started with Embedded Systems

As a CS student diving into electrical engineering, embedded systems felt like the perfect bridge between software and hardware. Here's what I've learned so far.

## Why Embedded?

Most software engineers work far removed from the hardware. We write code that runs on operating systems, abstracted away from the metal. But embedded systems programming is different—you're writing code that directly controls hardware.

## First Steps

I started with an Arduino, like most people. It's a great way to get your feet wet without dealing with complex toolchains. From there, I moved to:

1. **ESP32** - WiFi and Bluetooth built in, great for IoT projects
2. **STM32** - More professional, steeper learning curve
3. **Raspberry Pi Pico** - Affordable and well-documented

## What I've Learned

- Memory management matters (you don't have gigabytes to waste)
- Timing is everything in real-time systems
- Reading datasheets is a skill unto itself
- Debugging without a proper debugger is painful
